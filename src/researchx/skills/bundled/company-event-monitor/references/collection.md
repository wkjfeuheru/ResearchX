# 采集与时间规范

代码必须通过实际数据服务/公告核对公司名、交易所和行业，不凭简称猜测。可选MCP名称随运行时而变，先发现工具能力，不硬编码不存在的方法。
优先公告原文；新闻取得标题、发布机构、发布日期、链接及回应研究问题的正文。研报摘要作为观点来源，不能替代原研报。
默认上海时区now减7天至now，两端包含；用户给日期采用指定区间。只含日期时使用上海时区并说明时间精度。
至少尝试公告、新闻、研报摘要三类渠道；返回记录每个渠道的ok/failed/stale/summary_only状态，未访问不得标成功。
event_key由公司+事件分类+真实事项身份组成，转载相同事项使用同key，不同日期的新进展使用不同key。
脚本根据发布日分为窗口内、未知日期、窗口外；按发生时间优先排序，发生日期未知用发布日期。
冲突描述保留各来源，不通过投票把传闻变事实。渠道失败切换可用渠道，不能仅换词重复超时请求。
